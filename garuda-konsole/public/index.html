 Garuda Konsole 2.0

            
        

        

            

                
🎉 New in 4.0

                
    
                    
  • Installable PWA with push notifications for tasks, triggers & finished commands — even with the browser closed.
    • 
                    
  • Task Launcher (detached background jobs) + Scheduler (interval / daily / once, server-side).
    • 
                    
  • Floating control ball + working touch selection with an AI-powered action bar.
    • 
                    
  • Instant 60-second replay, file thumbnails + multi-select, share-sheet uploads.
    • 
                    
  • v5: GPT-OSS 120B/20B model picker, voice replies (Orpheus TTS), mic dictation (Whisper), live task logs, and notification/push fixes.
    • 
                

            

            

                
🤖 AI Guide (3.1)

                
    
                    
  • Tell the AI what you want in plain language — it plans and runs the shell commands for you in the active tab.
    • 
                    
  • 💬 Chat — advice only; suggested commands get a manual “Run once” button.
    • 
                    
  • 🔐 Ask (default) — every command shows an approval card: Run, Edit or Skip. The agent waits for you.
    • 
                    
  • ⚡ Auto — commands run as they are proposed, output feeds back automatically, until the task is done. Catastrophic patterns (rm -rf /, mkfs, dd of=/dev/…, fork bombs, shutdowns, curl | sh…) always require explicit confirmation, even in Auto.
    • 
                    
  • Stop halts the agent and sends Ctrl+C to the shell. The agent runs at most 12 commands per request.
    • 
                    
  • Your Groq API key lives server-side only (Settings → AI Guide) — it is never sent to the browser. Viewers/spectators cannot use the AI.
    • 
                

            

            

                
🚀 What's new in 3.0

                
    
                    
  • Split view — run two tabs side by side (vertical / horizontal), focus follows your click. Alt+S cycles modes.
    • 
                    
  • Session recorder & replay — record any tab's output, then replay it like a video: scrub, pause, 0.5–16× speed, export as JSONL.
    • 
                    
  • Triggers & alerts — regex-watch output for errors, build results or any pattern; fire toasts, sounds or push notifications.
    • 
                    
  • Session chat — talk with everyone connected to a tab (host, pair partners, spectators) without leaving the terminal.
    • 
                    
  • Tab profiles — pick the shell, start folder, name and color for each new tab (right-click the + button).
    • 
                    
  • Live cwd & git branch — the status bar follows your shell's folder and shows the current git branch with a dirty flag.
    • 
                    
  • Light themes & day/night auto-switch, plus theme import/export as JSON.
    • 
                    
  • Activity center — timeline of long commands, triggers, share events and uploads, with session insights.
    • 
                    
  • File manager v2 — recursive name search, image preview, full file details (permissions, owner, times).
    • 
                    
  • Pinned macro bar — one-tap strip for your favorite commands, on desktop and mobile.
    • 
                    
  • Smoother heavy output — frame-batched terminal writes keep huge outputs fluid.
    • 
                

            

            

                
✨ From 2.0

                
    
                    
  • Session restore — refresh the page and every tab reconnects to its living shell with full scrollback replay.
    • 
                    
  • Command palette — fuzzy search across actions, macros, recent commands and themes.
    • 
                    
  • Shell revive — if a shell exits, restart it in place without losing the tab.
    • 
                    
  • Mobile command deck — sticky Ctrl modifier, symbol row, arrows, tab navigation, haptics, collapsible keyboard.
    • 
                    
  • Log export — save any tab's scrollback as a .log file.
    • 
                    
  • Themed UI — the whole interface follows your terminal theme, with adjustable background opacity.

📱 Mobile tips

                
    
                    
  • Sticky Ctrl — tap Ctrl once, then any letter key on the OS keyboard combines (e.g. Ctrl+C).
    • 
                    
  • Symbol row — tap +/- to reveal pipe, slash, tilde and friends.
    • 
                    
  • Alt Lock — freeze the soft keyboard, select a filename in the output and it downloads instantly.
    • 
                    
  • Scroll buttons — hold ▲/▼ for smooth continuous scrolling.
    • 
                    
  • Collapse — tap ⌄ to hide the control deck for maximum screen.

 What's new in 4.0

            
        

        

            

                
📲 Install it like a real app

                
    
                    
  • Chrome can now install Garuda Konsole (proper PNG icons + manifest). Needs HTTPS or localhost — see README for 3 easy ways (adb reverse, Caddy TLS, tailscale).
    • 
                    
  • Share sheet → Garuda: installed PWAs appear in Android's share menu; shared files land in ~/GarudaUploads.
    • 
                

            

            

                
🔔 Web Push — notifications with the browser closed

                
    
                    
  • Background push for: finished tasks, trigger matches (server-side!), shell exits and finished long commands — even when nothing is open. Enable in Settings → Notifications.
    • 
                

            

            

                
🚀 Task Launcher &  Scheduler

                
    
                    
  • Run commands detached in the background with live tail logs, kill/re-run — they survive closing the browser.
    • 
                    
  • Interactive tasks (4.1): if a background task asks for a password or y/n, you get a push + a “needs input” chip and can answer right in the Tasks drawer.
    • 
                    
  • Schedule them: every N minutes, daily at a time, or once. All server-side.
    • 
                

            

            

                
📱 Mobile superpowers

                
    
                    
  • Floating control ball — drag anywhere, tap for Esc/Tab/Ctrl/arrows. Collapse the whole keyboard deck for good.
    • 
                    
  • Touch text selection that finally works: long-press selects a word, horizontal drag selects a range — no keyboard pop-up, no native copy/paste bubble. A custom bar offers Copy / Explain with AI / Fix with AI / Download.
    • 
                    
  • File manager: thumbnail grid, multi-select bulk download/delete.
    • 
                

            

            

                
⏪ Instant replay & 🤖 AI polish

                
    
                    
  • Replay last 60 s of any tab (right-click → Replay recent). Ring buffer prunes inline with output — zero timers, zero idle cost, hard 2 MB cap per tab.
    • 
                    
  • AI approval cards now always scroll into view & open the drawer; auto mode is badged; approval waits notify you.
    •
